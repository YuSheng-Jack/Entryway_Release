# Entryway Android TV 1.0.11

TV 独立正式版，构建号 **55**，Release + R8、正式发布证书签名，提供 arm64-v8a 与 armeabi-v7a 两个安装包。手机版保持 1.0.12；Entryway 永久免费。

本版汇总此前 TV Preview 的 NAS、播放、Mine 与遥控交互改进。由于当前测试盒子异常，本次没有进行新正式包的装机验收；欢迎按下方重点提供设备反馈。

## 更新

- 改进服务器添加和编辑布局，常用字段集中显示；飞牛影视/音乐保存 FN Connect 模式和原始 FN ID 入口，恢复账号时重新解析连接地址，支持用户名密码及可选网页授权、访问码网关会话恢复。
- 修复飞牛音乐冷启动后无法恢复访问码会话的问题，完善影视/音乐切换和真实收听账本、Mine 年度音乐数据展示。
- 修正退出播放时的停止位置采样，减少暂停后远端续播偏移；播放引擎切换后重新绑定账本记录，避免回退 Exo 后仍被标为 mpv。
- 改进 Mine 年度统计、观看记录海报、空白标题和收藏统计；完善账号隔离、错误信息脱敏与本地资料保护。
- 整合推荐首页、TMDB 详情及跨服资源匹配，修复登录成功后的首页路由和跨行遥控焦点，避免焦点偏移引起误播。
- 修正 mpv 重复绑定 Surface 的引用泄漏，统一旧画面输出的释放顺序；增加实际硬解状态、软解回退和欠载诊断。
- 已知 DBBOX5C / rk30board / Android 11 的普通 4K HEVC 兼容路径保留 ExoPlayer 保护，避免直接进入已发生欠载和原生崩溃的 mpv 路径；不扩展到所有设备、光盘菜单或必须使用专用色彩重建的路径。

## 已知限制与反馈重点

- **mpv 原生 4K HEVC 欠载及冷续播崩溃尚未完成根因修复与真机闭环。** Surface 修正不代表这两项已修复，自动回退 Exo 也不算原生 mpv 验收通过。
- 历史测试盒子按 Home 后，音乐前台服务仍被系统强制停止；本版不承诺该设备后台音乐已解决。
- FN ID 真实外网换网、IPv6、其他分辨率/字体设置及更多用户账号仍需实际验证。ISO 文件可用性和 NAS Range 超时另行排查；源海报接口失效时仍可能显示标题占位。
- 本轮相关模块单测 1,676 项：1,673 通过，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；正式包未安装到实机。历史 Preview 验收与当前正式包验收分开记录。

建议重点反馈：退出/冷启动续播、暂停与跳转后的进度、1×/2×计时、账号切换后的 Mine/观看记录归属、FN ID 冷启动连接、飞牛音乐冷启动及 Home 后播放。反馈请附设备型号、系统版本、服务器类型、所用引擎、影片编码/分辨率和复现步骤；请勿公开账号密码或带令牌的播放链接。

## 安装

已安装 TV 1.0.1 及以后正式版可直接覆盖升级，建议先备份服务器配置与观看账本。64 位系统选择 arm64-v8a，32 位系统选择 armeabi-v7a。独立 Preview 与正式包包名不同，不会自动迁移 Preview 数据。更早的不同签名版本需先备份，再卸载旧版、安装并恢复；不要直接卸载后丢失数据。
