# Entryway Android Phone 1.0.13

版本 1.0.13 · 构建号 73 · 正式 Release · Android 8.1+ · arm64-v8a

这是 1.0.12 之后的完整功能版本，汇总用户反馈 #9–#59 中手机端的大部分需求与问题，以及杜比视界、飞牛、SMB、TVBox/IPTV 和外部备份导入等改进。TV 独立发布 1.0.12；Entryway 永久免费。

## 新功能

**播放与杜比视界**
- 杜比视界硬件修正路径：设备有 DV 解码器时经 ExoPlayer 原生播放；mpv 支持 mediacodec-copy 硬解修正（着色器缓存、首帧后校验），媒体信息新增视频解码器与杜比视界行。
- mpv 播放 Dolby Vision Profile 5/8 时可交给系统解码器（受信平台），失败或超时自动回到常规路径。
- 字幕在线搜索：Emby/Jellyfin 远程字幕、OpenSubtitles 与射手网（Assrt），使用你自己的密钥；自动解压 gzip/zip 并转为 UTF-8（#54）。
- 播放器内调整字幕底部边距，记住画面比例与缩放，双指连续缩放 0.5×–3×（#42）；画面比例记忆与“自适应/拉伸”问题修正（#18、#19）。
- 播放保号提醒（#29）。

**首页、媒体库与资源**
- 首页各行可打开完整网格，首选画质多条件同时满足（#45）；可按单个媒体库添加首页组件（#24），首页分类间距收紧（#17）。
- 媒体库筛选“未观看/已观看”，已观看标识更醒目（#12、#13）；按播放时间排序时未播放项排序更准确（#11）。
- 资源页按服务器类型筛选（#30）；每个服务器可写备注，显示在资源卡片并随备份保存（#53）。
- 首次启动可“跳过”，不添加服务器也能使用本地文件和网盘（#43）。
- 自定义徽章包（#27、#33）；自定义组件支持 `.fwd` / `.rex` 订阅（#32）；Trakt 可改用自定义 Client ID（#31）。

**飞牛、线路与网络**
- 多线路自动故障切换：线路不可用时自动换到其他可用线路（#15、#26）。
- 飞牛：完整媒体库分页（大库、多库不再截断）、IPTV 频道、外挂字幕下载；每路播放独立会话，先关闭旧转码；FN Connect 访问码与网关 Cookie（#35）；FN ID 识别修正，不再把随意输入识别成 FN Connect（#36）。
- SMB 播放提速：SMB 3.1.1 协商、空闲会话过期重建、1 MiB 预读，慢服务器不再拖住其他存储（#59）。
- IPTV 播放列表上下文解析更稳健，TVBox 配置子集解码改进。

**备份**
- 可导入与导出 Hills、AfuseKt、Yamby、CapyPlayer 备份：分阶段写入、失败回滚，导入后列出需重新登录的账号，未能导出的字段会标出。

**用户群**
- 用户群迁移到 Telegram（Entryway Buddys），关于页二维码随之更新；致谢名单新增三位支持者。

## 修复

- 投屏期间保持局域网中转不被系统回收，容忍渲染器短暂异常，CDN 链接失效时回到服务器地址（#41）。
- 修复飞牛把普通视频报为 `dv_profile=0` 时被当成杜比视界、只有声音没有画面（#50）。
- 飞牛“继续观看”打开所在剧集并从断点续播（#37）；FN Connect 中转不再收到登录页，FN ID / FN Connect 下的 ISO 给出明确提示。
- 开始播放沿用当前媒体音量，不再固定跳到较大音量（#38）。
- 首页轮播显示完整清晰图（#44）；竖屏显示“上一集”（#47）；上一集/下一集保持在正在播放的服务器和剧集内（#48）。
- 弹幕不再盖住播放器面板和对话框（#55）；横屏弹幕匹配对话框使用全屏高度，结果可正常滚动选择（#56）。
- 1 MB 以下的 strm 不再显示为 0（#14）。
- 关闭开屏致谢后，部分设备（如 vivo）恢复界面时不再卡在致谢层、无法进入应用（#25）。
- 安装包同时带 v1（JAR）与 v2 签名，修复荣耀 MagicOS 7 提示“无证书”无法安装（#28）。

## 验证与已知限制

- 本轮在合并后的 main 上运行全部模块单元测试 2,468 项：2,465 通过、0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过。已核对包名、版本、ABI、正式签名（v1 + v2）、非调试属性与弹弹Play native signer，包内无 AppSecret 明文。
- 本次正式包未安装到实机做全量验收。杜比视界两条新路径、字幕搜索、外部备份导入和 FN Connect 在更多设备与服务器上的表现欢迎反馈。
- 外部备份导入只覆盖上述四个应用；目标应用未导出的字段无法恢复。

## 升级
