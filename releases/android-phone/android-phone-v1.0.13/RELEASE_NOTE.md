# Entryway Android Phone 1.0.13

版本 1.0.13 · 构建号 73 · 正式 Release · Android 8.1+ · arm64-v8a

本版汇总用户反馈 #37–#59 的修复与改进。TV 独立发布 1.0.12；Entryway 永久免费。

## 新功能

- **字幕在线搜索**：通过 Emby/Jellyfin 远程字幕、OpenSubtitles 与射手网（Assrt）搜索下载字幕，使用你自己的密钥；自动解压 gzip/zip（RAR/7z 不支持）并转为 UTF-8（#54）。
- 播放器内调整字幕底部边距（两种引擎实时生效），记住画面比例与缩放，双指连续缩放 0.5×–3×（#42）。
- 首次启动可“跳过”，不添加服务器也能使用本地文件和网盘（#43）。
- 首页各行可打开完整网格；首选画质的多个条件改为同时满足（#45）。
- 每个已保存服务器可写备注，显示在资源卡片上并随备份保存（#53）。
- mpv 播放 Dolby Vision Profile 5/8 时交给系统解码器（受信平台），失败或超时自动回到常规路径。

## 修复与改进

- 投屏期间保持局域网中转服务不被系统回收，容忍渲染器短暂异常，预解析的 CDN 链接失效时回到服务器地址（#41）。
- SMB 播放提速：SMB 3.1.1 协商、空闲会话过期重建、1 MiB 预读，慢服务器不再拖住其他存储（#59）。
- 修复飞牛把普通视频报为 `dv_profile=0` 时被当成杜比视界、只有声音没有画面的问题（#50）。
- 飞牛“继续观看”打开所在剧集并从断点续播，而不是进入第 1 季从头播放（#37）。
- 开始播放时沿用当前媒体音量，不再跳到上次播放器的音量（#38）。
- 首页轮播显示完整清晰图，而不是长时间停留在低清占位图（#44）。
- 竖屏显示“上一集”按钮（#47）；上一集/下一集与自动下一集保持在正在播放的服务器和剧集内（#48）。
- 弹幕不再盖住播放器面板和对话框（#55）；横屏弹幕匹配对话框使用全屏高度（#56）。

## 验证与升级说明

- 本轮在合并后的 main 上运行全部模块单元测试 2,290 项：2,287 通过、0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；已核对包名、版本、ABI、正式签名、非调试属性与弹弹Play native signer，包内无 AppSecret 明文。本次正式包未安装到实机做全量验收。
- Dolby Vision 系统解码路径与字幕搜索在更多设备、服务器上的表现欢迎反馈。
- 正式签名与包名延续既有版本，1.0.1 及以后正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。
