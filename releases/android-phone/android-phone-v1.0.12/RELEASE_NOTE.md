# Entryway Android Phone 1.0.12

版本 1.0.12 · 构建号 72 · 正式 Release · Android 8.1+ · arm64-v8a

这是针对 1.0.11 卡顿问题的性能热修复，建议已安装 1.0.11 的用户尽快覆盖升级，无需卸载或清空数据。TV 本次保持 1.0.10。

## 修复内容

- 修复账号凭据在每次读取时重复访问 Android Keystore 的问题，减少启动、页面加载、切换服务器和开始播放时的停顿。
- 已解密的凭据只在当前进程内有限缓存；写入时仅重新加密发生变化的字段，文件中的账号凭据仍保持加密。
- 复用文件源密钥句柄，减少重复的 Keystore 查询；系统拒绝密钥时清除句柄缓存，后续重新获取。
- 缓存服务器证书信任配置及相同地址、证书链的校验结果，避免连接复用时重复完整验证。证书或信任配置变化会使旧缓存失效，校验结果也有有效期。
- 优化媒体格式徽标的重复解析及发行组匹配，修正徽标较少时没有靠左显示的问题。

## 验证与升级说明

- 核心修复来自 Qoder 提交 `a1258ded`。Qoder 报告 PKT110 真机冷启动后 12 秒内 keystore2 CPU 从 87–99 ticks 降至 0–1 ticks，详情页从 10–12 ticks 降至 0；这些是该设备及当轮环境的数据，不代表所有设备的统一性能承诺。
- 本轮发布复核修复文件哈希、重新运行单测并构建正式签名 R8 包；不将 Qoder 的同源码真机结果表述为本轮对正式 APK 重新完成的全量真机验收。
- 正式签名与包名延续既有版本，1.0.1 及以后正式版可覆盖升级；不同包名的独立 Preview 请使用其自身数据迁移方式。
- Entryway 永久免费。App 的授权兼容接口保留但收费逻辑固定关闭，历史授权服务独立归档，没有接入、启动或部署。
- 本次没有改变 NAS、片源或设备解码兼容边界；原环境的偶发播放、特定 DV/EAC3 和 FN Connect 外网场景仍按各自验收进度跟进。
