# Entryway Android Phone 1.0.14

版本 1.0.14 · 构建号 74 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.13 之后的功能版本：推荐页不再需要 TMDB 密钥、推荐影片的详情页按天缓存，汇总用户反馈 #39、#60–#95 中手机端的需求与问题，并改由自有双云下载服务检测与下载更新。TV 独立发布 1.0.13；Entryway 永久免费。

## 新功能

**推荐页**
- 没有 TMDB 密钥时，推荐页的 TMDB 组件自动改读豆瓣对应榜单，分类浏览也走豆瓣；填写密钥后自动换回 TMDB。
- 推荐、榜单、TMDB 与豆瓣里的影片（包括已入库的）统一打开影片详情：信息优先取自 TMDB，下面列出全部服务器上的资源与版本；都没有时显示“所有服务器检索暂无结果”。
- 推荐影片的详情、各服务器资源与剧集首季每天自动缓存：打开即显示，再在后台重新检索服务器；不在推荐里的影片在下次刷新时清除。
- 豆瓣海报与剧照改用最高分辨率；轮播与详情大图优先选用无文字的剧照（#89）。

**播放**
- 字幕偏好新增“中英双语”；两个播放内核都支持灰色与自定义字幕颜色；新增“原声”音轨偏好，从 TMDB / 豆瓣详情页播放时同样生效（#95）。
- 进度条显示已缓冲到的位置（#94）。
- 左侧长按慢放可单独关闭（#74）。
- 资源排序可选“优先按资源页的服务器顺序”，PGS 图形字幕计为特效字幕（#71）。
- 字幕搜索新增 SubDL（需自己的 API Key），SubHD 改为打开其网站（#65）。

**追剧与记录**
- 详情页可直接在 MoviePilot 订阅影片，订阅的剧集出现在追剧日历（#88）。
- 继续观看长按可“标记为已观看”（开启同步时一并写入 Trakt 历史）或删除观看记录（#39）。
- Trakt 同步更准确：超过 5 分钟才补发的“看完”按原始观看时间写入历史；30 分钟内未发出的“开始播放”不再补发，避免误显示正在观看；单条历史写入前先标记，重试时先查历史，已写入就不再重复。

**本地影视库**
- WebDAV、SMB 与本地文件夹刮削可设置扫描线程数（1–8），网盘仍逐个文件夹扫描（#86）。

**备份与更新**
- 跨版本恢复备份：逐项读取服务器、存储、来源与书签，无法读取或本版本不支持的项目单独列出，不再整份失败或误报密码错误。
- 检查更新与下载安装包改用自有双云下载服务（杭州为主、上海备用、GitHub 兜底），支持断点续传与 SHA-256、签名校验。

## 修复

- 播放器：连接期间显示“连接中…”而不是 0；30 秒毫无进展会报错，不再一直转圈（#87）。实时网速按 3 秒平均，不再在 0 与峰值之间跳动（#93）。SMB 小块读取更快返回，网速显示真实接收速度（#75）。
- 内嵌 DVB 图形字幕不再被服务器烧录进转码，由 ExoPlayer 直接显示（#76）；音轨按实际播放的流标注语言（#62）；缺少 AI 设置的提示每次只出现一次（#66）。
- 被 TMDB 单独收录的季（如《现在就出发 第四季》）也能在服务器上找到（#73）。
- 人物页头像不再被压扁，每部作品都能打开，确实没有时才标“未入库”（#72）；首页轮播与详情页大图构图一致、不再模糊（#70）。
- 飞牛 fnOS：媒体库分类可排序，服务器统计显示各库数量（#67、#60）。
- 弹幕菜单直接显示匹配到的剧名、集数、来源与条数，面板文字清晰（#69）。
- 直播节目单标出正在回看的节目（#63）；资源卡片菜单分开“修改显示名称”与“修改备注”（#61）；设置卡片说明文字不再贴边（#63、#64）。
- “发送到电视”提示指向 TV 上真实的“用手机配置”入口。

## 升级

正式签名与包名延续既有版本，1.0.1 及以后的正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。1.0.13 及更早版本仍通过原有渠道发现本次更新；升级到 1.0.14 后，之后的更新改由双云下载服务提供。

## 验证与已知限制

- 在合并后的 main 上运行全部模块单元测试 2,648 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；TV lint 无错误。已核对包名、版本、ABI、正式签名（v1 + v2）、非调试属性与弹弹Play native signer，包内无 AppSecret 明文。
- 推荐页缓存与详情在真机上用同代码的 R8 测试包验证：推荐影片详情 0.8 秒打开。本次正式包未在实机做全量验收；杜比视界、双云更新在更多设备上的表现欢迎反馈。
- 没有 TMDB 密钥时，推荐影片的详情来自豆瓣；豆瓣对单个公网地址的访问有频率限制，频繁打开大量未缓存影片时可能暂时取不到详情。
