# Entryway Android Phone 1.0.19

版本 1.0.19 · 构建号 79 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.18 之后的功能版本：杜比视界与 HDR 画面大幅增强（HDR 转杜比视界、SDR 转 HDR、杜比视界原生播放下的特效字幕），原盘可以选标题、打开更快，AI 字幕支持本机语音识别，新增 Stremio 插件、组件管理、本地私有歌单和自定义下载目录，并汇总用户反馈 #302–#338 中手机端的问题。TV 独立发布 1.0.18；Entryway 永久免费。

## 新功能

**杜比视界与 HDR**
- HDR 转杜比视界：在支持杜比视界的屏幕上，HDR10+ / HDR10 / HLG 视频可以转成杜比视界 Profile 8.1 / 8.4 播放；「HDR 转杜比视界」可选自动（默认）、关闭、仅 HDR10+、全部 HDR，同时带杜比视界和 HDR10+ 的片源可以选优先哪一种。
- SDR 转 HDR：普通 SDR 视频实时转成 HDR 显示，播放器里可以调强度，并显示当前是否已在输出 HDR；mpv 另有反色调映射等级和 4K 开关。
- 杜比视界增强：更完整的动态元数据解析、按亮度信息引导的色调映射、mpv 上 Profile 7 转 8.1、双层（EL）片源支持；播放中可以快速切换杜比视界处理方式，并查看完整的信号链诊断。
- 杜比视界硬解修正改走零拷贝，CPU 占用更低。
- 杜比视界原生播放时也能显示 ASS 特效字幕和 PGS 图形字幕，并可以调 HDR 下的字幕亮度。
- 平滑模式：mpv 按屏幕刷新率混合帧，画面运动更顺。

**播放**
- 原盘：蓝光可以在播放器里选择标题并原地切换；同一个 ISO 30 秒内再次打开直接复用，不用重新读盘；远程 ISO 打开和拖动更快（#302、#335）。
- 解码失败时自动从硬解降到软解，并记住这个文件，下次直接用合适的方式。
- 播放器里可以调弹幕速度并实时预览（#304）。
- 可以自定义播放器显示哪些按钮；控制层新增章节、截图和手势说明，并能避开屏幕圆角。
- 播放中可以切换服务器线路，并能读取服务器提供的扩展线路。
- 从播放器直接打开当前内核的设置；全屏编辑 mpv.conf，支持导入文件，逐行提示写错的配置。
- 视频可以后台播放声音，并显示系统媒体控制。
- 字幕简繁转换。
- 从 ExoPlayer 切到 mpv 时保留已选的字幕。
- 点播断流后自动重连；mpv 内存缓存按设备内存分配；存储空间不足时停止磁盘缓存；按流量计费的网络上缩小预读，不写磁盘缓存。
- 片头片尾识别增加一个补充数据源。

**AI 字幕**
- 支持在手机本机做语音识别生成字幕，不依赖联网服务。
- Gemini 实时翻译可以作为字幕来源。
- 整个字幕文件一起翻译，人名和术语前后一致，分批翻译更稳。

**内容与发现**
- Stremio 插件：首页显示插件的目录，详情页显示插件提供的播放源。
- 组件管理：预览、更新、启用 / 停用、测试和请求记录；组件可以出现在全局搜索、详情页播放源和弹幕来源中。
- 动漫详情页可以看 Bangumi 评论和剧照。
- 首页布局可以分享给别人，也可以导入别人分享的布局。
- 详情页剧照可以全屏查看。

**下载与音乐**
- 可以自定义下载目录（选择手机上的任意文件夹），支持断点续传，下载的视频在文件管理里就能找到（#333）。
- 下载时一起保存弹幕，离线也能看弹幕；离线播放支持所选文件夹里的视频和 ISO。
- 音乐支持本地私有歌单：新建、导入、编辑、播放，歌曲可以来自不同的服务器（#323）。

**图片、存储与隐私**
- 新增图片质量设置；图片缓存可以设置保留时间、按服务器清理，空间不足时自动清理。
- 存储空间按类别显示，并可以分别清理。
- 应用内查看日志和崩溃记录。
- 显示出来的私密服务器离开 30 秒后自动重新隐藏。

## 修复与优化

- 继续观看：某台服务器刷新失败时，保留其他服务器和之前缓存的记录（#338）。
- CMS 搜索支持首字母和中英混合拼音（#312）；分类标错的 CMS 片源不再被过滤掉，推荐页海报点进去能找到 CMS 资源（#326）；文件夹浏览保留所选排序（#320）。
- IPTV：EPG 下载或解析失败后会重试，不再等一小时（#317）；回放时节目单定位到当前回放的日期和节目（#311）；回放和直播不再继承无关的续播进度（#318）。
- Emby 云盘服中 strm 指向的 ISO：没有跳转地址或不支持分段读取时自动改用直接地址（#302、#335）。
- 网盘直链过期或被限速时自动刷新地址，遇到 429 / 5xx 和不完整的数据会重试（#328、#330、#331、#332）。
- 退出横屏播放后，资源和设置页不再整体偏向右边（#336）。
- 杜比视界：Profile 7 转 8.1 的解码器配置修正；自带杜比视界的手机上 GPU 重整形快速切换修复；修复等待 mpv 时可能出现的无响应。
- 详情页首屏更快；跨服务器结果 5 分钟后自动刷新；修改服务器图片后各处立即更新。

## 升级

正式签名和包名都与之前的版本相同，1.0.1 及以后的正式版可以直接覆盖升级。建议升级前先在「设置 › 备份与恢复」备份。
