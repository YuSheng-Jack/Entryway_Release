# Entryway Android Phone 1.0.17

版本 1.0.17 · 构建号 77 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.16 之后的功能版本：资源里可以直接播放网盘分享链接，新增 AList / OpenList 和 UC网盘，TVBox 配置兼容大幅增强，并汇总用户反馈 #175–#240 中手机端的问题。TV 独立发布 1.0.16；Entryway 永久免费。

## 新功能

**网盘与资源**
- 粘贴夸克、115、天翼云的分享链接或分享文本（打开时会读一次剪贴板），用自己的账号打开。需要先转存才能播的，会先征得你的同意再「临时转存」；转存的副本 24 小时后或下次启动时移到回收站。139、光鸭的分享链接目前只能识别，建议通过 AList 播放。
- 新增 AList / OpenList 存储（API 接入）：支持密码、令牌、游客登录；服务器建了索引时可以全盘搜索；公网使用明文 http 时会提醒。已有的 AList `/dav` WebDAV 存储可以一键「改用 AList API 连接」。
- 新增 UC网盘：用 drive.uc.cn 的 Cookie 登录，支持多连接读取。
- 夸克文件页面最多 16 路并发读取，内存小的设备自动减少连接数。
- 网盘登录失效时，卡片显示「需要重新登录」，在菜单里原地重新登录即可，存储和媒体库都不受影响。

**TVBox**
- 多仓可以选择具体配置；导入后列出被跳过的站点和原因。
- 支持 `json:` / `parse:` 前缀和 DIYP 节目单；m3u8 广告过滤（默认开启）；可选用配置自带的 hosts / DoH。
- 支持 T4 站点及点播分类上方的「筛选」标签；T4 站点的字幕作为外挂字幕加载。
- CMS 站点、合集和 IPTV 列表的卡片菜单把「重新登录」换成「重新检查」，结果用提示条显示。

**播放**
- 交互 › 默认倍速下新增「记住倍速」，默认关闭；直播和长按临时加速不会被记住（#227）。
- 「画面与HDR」的「HDR 显示输出」和「强制 HDR 色彩模式」合并为一项「HDR 输出」：自动（推荐）/ 始终 HDR / 转为 SDR。仅对 MPV 生效，从下一个视频开始。选「自动」时，峰值亮度低的屏幕（Android 16+）会转为 SDR，解决部分 LCD 平板开了 HDR 反而变暗的问题。旧设置会自动换算（#234、#235）。

**界面**
- 字体页新增「界面文字大小」：85% / 90% / 100% / 110% / 120%，叠加在系统字号设置上，字幕和弹幕大小不受影响（#240）。
- 音乐条和标签栏共用底部一个位置：在标签栏上从左向右滑动会出现「切换」按钮；搜索按钮并入标签胶囊（#182）。
- 在「设置 › TMDB › 网站评分」填入自己的豆瓣 Cookie 后，网站评分行最前面显示豆瓣分（#193）。
- 音乐首页新增「当前媒体库」，可以切换 Navidrome 的媒体库（#183）。
- TMDB 列表行改用无文字海报（#198）；横版封面占多数的首页行自动改用横版卡片（#181）；「外观」里的封面开关对首页和推荐卡片同样生效，封面可以显示评分角标（#197）。

## 优化

- 高码率多连接取流按内存自动选择并发，高延迟网络下更快（#187、#204、#211）。
- 详情页不再白闪，最近看过的详情直接显示（#194）；刷新失败不会关掉详情页和播放器（#192）。
- 播出信息移到季标题旁，显示播出时间和集数范围；追剧日历返回下一播出日的全部集数（#195）。
- 网站评分行出现时不再重复显示星级，内容固定一行、可横向滑动（#196）。
- 豆瓣「热门国漫 / 纪录片 / 儿童片」只保留近期作品（#198）。
- 本地文件的上一集 / 下一集按文件夹的自然顺序，已下载剧集按季、集顺序（#179）；文件列表统一自然排序，E9 < E10 < E100（#191）。
- 弹幕开启时请求屏幕最高刷新率，控件隐藏后不再卡顿（#206）；弹幕面板用你的语言说明失败原因。
- 备份包含脚本组件和自己添加的精选合集（#208）。没有设置备份密码时，备份不带网盘登录信息，恢复后会列出哪些需要重新登录。

## 修复

- 换集时沿用了上一集的杜比版本和音轨 / 字幕选择，这可能就是 MPV 换下一集闪退的原因（#225）。
- MPV 关闭字幕后，屏幕上最后一行不消失（#226）。
- 从 TMDB 搜索结果或播放书签进入播放时，没有上一集 / 下一集、选集和自动连播。
- 竖屏时播放器下半屏手势没反应（#180）。
- 二级页面底栏不随滚动收起，列表最后一项被底栏挡住（#212）。
- 竖屏平板首页 / 推荐轮播的背景图下半截全黑（#219）。
- mpv「实时播放统计」的输出帧数一直显示「—」，这一行现在只在 ExoPlayer 下显示（#221）。
- 滑动调亮度引起的卡顿和黑闪（#175、#220）。
- 光盘 ISO 在限制连接数的服务器上每 2–3 秒缓冲一次（#184、#189、#203）。
- Emby / Jellyfin 音乐搜索把媒体库当成歌手、专辑、歌曲返回。
- 部分 SMB 服务器列不出共享（#200）；飞牛 fnOS 的海报和背景图缺失（#205、#209）。
- UC / 夸克非会员拿到的占位片段会明确报错，不再当正片播放。

## 升级

正式签名和包名都与之前的版本相同，1.0.1 及以后的正式版可以直接覆盖升级。建议升级前先在「设置 › 备份与恢复」备份。

## 验证与已知限制

- 在合并后的候选代码上，全部模块单元测试 3,601 项，0 失败。已核对包名、版本、ABI、正式签名、libdandansign，并确认包内没有 AppSecret 明文。
- #226、#227、#234、#235、#240 以及从 TMDB 进入播放的上一集 / 下一集，已在一加 PKT110 上验证。#225 的换集闪退没能在真机上复现，只修了确定存在的状态问题。
- 网盘分享、AList、UC网盘、TVBox 新功能、底栏改版、Navidrome 多媒体库和亮度修复，目前只有单元测试或模拟服务器验证，欢迎反馈。
