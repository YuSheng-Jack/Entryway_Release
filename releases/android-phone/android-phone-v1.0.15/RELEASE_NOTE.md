# Entryway Android Phone 1.0.15

版本 1.0.15 · 构建号 75 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.14 之后的反馈修复版本：实时播放统计、1.75× 倍速、追剧日历与详情页联动、播放中调整倍速与字幕样式、CMS 点播源分页与过滤、Jellyfin 官方片头片尾，汇总反馈 #109、#111–#113、#115、#122、#127、#133、#136、#138、#140、#145、#149、#153–#155。TV 独立发布 1.0.14；Entryway 永久免费。

## 新功能

**播放**
- 媒体信息新增“实时播放统计”：Exo 与 mpv 都显示输出帧率和各类掉帧数，从 Exo 切到 mpv 后不再显示旧数值，不影响播放（#155）。
- 倍速菜单、设置 › 交互与音乐播放器都提供 1.75×（#154）。
- 播放器内可调整倍速、字幕字号与颜色，Exo 与 mpv 都立即生效；长按倍速可半档调整，松手恢复原速；PGS 等图形字幕会说明无法修改；弹幕样式可实时调整（#136）。
- 可关闭设置 › 交互 ›“显示上一集和下一集按钮”，选集菜单、自动连播与快捷键不受影响（#145）。
- 可选“记忆播放亮度”：下次播放恢复上次手势调好的亮度，退出播放、切到后台或进入画中画时恢复系统亮度（#109）。

**追剧日历**
- 详情页显示“预计播出：日期 · SxxEyy”，点击跳到日历并定位到这部剧（#138）。
- 同名但 IMDb / TVDB 不同的剧不再借用对方的日期；同一服务器上同一集有两份、其中一份看过时显示“已看”，重叠集数各自保留（#138、#140）。

**推荐与字幕**
- 推荐页可添加“热门国漫”“热门纪录片”“热门儿童片”（#133）。
- 在线搜索字幕的压缩包支持旧式 ZIP，中文文件名能正确读出；字幕下载跳转时不把服务器凭据带到其他网站（#112）。

## 修复

- **CMS（TVBox / 苹果 CMS）点播源（#149）**：先按类型过滤再分页，首页刷新不再扫描整个站点；“查看全部”可以一直往下翻、不重复；直播与轮播条目不再出现在电影、剧集行；无类型列表照常显示；CMS 收藏不丢。
- **Jellyfin 片头片尾（#153）**：读取服务器识别的全部片段类型，片尾跳过提示正常出现，跳过后不会被拉回或反复提示，片尾不超出片长；手动设置的片头片尾优先。
- 剧集库“最近添加”中有新集的剧排到前面（#115）。
- 跨服务器“是否已入库”查询失败时显示失败，不再说“没有”（#127）。
- 推荐卡片图片加载失败时显示占位图（#122）。
- 横屏或短屏下字幕搜索结果可以滚到底（#113）。
- 服务器报为普通 HEVC、实际为杜比视界 P5 的片源不再出现绿紫画面（#111）。

## 升级

正式签名与包名延续既有版本，1.0.1 及以后的正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。1.0.14 起应用内更新由双云下载服务提供。

## 验证与已知限制

- 在合并后的 main 上运行全部模块单元测试 2,876 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；`:tv-app:lintDebug` 无错误。
- 已核对包名、版本、ABI、正式签名、非调试属性与弹弹Play native signer，包内无 AppSecret 明文。
- 本版改动以单元测试为主，正式包未在实机做全量验收；#155 中反馈的“调亮度黑屏”本版未修复；CMS 直播条目按名称识别，可能有漏判，欢迎反馈条目名。
