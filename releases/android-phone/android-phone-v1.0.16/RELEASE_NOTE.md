# Entryway Android Phone 1.0.16

版本 1.0.16 · 构建号 76 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.15 之后的功能版本：主动提示新版本，详情页增加网站评分和获奖信息，支持竖屏短剧模式和批量标记已看，并汇总用户反馈 #107–#177 中手机端的问题。TV 独立发布 1.0.15；Entryway 永久免费。

## 新功能

**更新**
- 回到主页时自动检查新版本，每天最多一次；有新版本时在底栏上方显示提示条，播放时不会打扰。检查失败不显示任何提示。
- 手动检查更新不再受“跳过此版本”影响，跳过后也能重新找到这个版本。

**详情页**
- 简介下方显示 TMDB、IMDb、烂番茄、Letterboxd、Trakt、Metacritic 的评分。需要在「设置 › TMDB › 网站评分」填写自己的 MDBList API Key，不填不显示。
- 评分下方显示作品获得的知名奖项，可展开查看全部；只算获奖，不算提名。
- 剧集显示已播放标记，可将本季标记到某一集为已看，确认前会预览涉及的集数，完成后报告结果（#176）。
- 追剧日历包含今天，改为紧凑入口，日期单独显示在季标题下方；没有具体时间的日期不再补出时间（#166）。

**播放**
- 竖屏短剧模式（默认关闭，在交互设置中开启）：按画幅识别竖屏内容并竖屏播放，上滑下一集，下滑上一集（#167）。
- 在线字幕搜索到多文件字幕包时可以选择文件；zip 和 gz 包优先，RAR 和 7z 用文件列表（#174）。
- HDR 屏上，杜比视界 GPU 修正改为输出 HDR10，媒体信息显示路径和曲线对帧情况。

**片源**
- CMS 站点可以填写 Cookie，TVBox 站点会保留整组请求头；这些只随该站点的播放请求发送。
- 落在夸克网盘的线路改用 16 连接分段读取，ExoPlayer 和 mpv 都支持。

## 修复

- 剧集列表不再只显示 50 集；服务器总数报错或忽略分页时也能读完（#164）。
- 终点站等服务器的类型筛选不再返回整个媒体库；不再显示“1996 - 1970”这样的年份。
- emos 等服务器返回自有播放地址时按该地址播放（#161）。
- Emby 外挂字幕优先使用服务器提供的地址，mpv 不再丢失外挂字幕（#162）。
- 在线字幕搜索结果可以独立滚动，横屏下来源和语言行可折叠（#160、#163）。
- 合并季里其他文件夹的集数不再从播放器选集消失（#143）；选集缩略图不再被拉伸（#169）。
- 没有季海报时回退到剧海报（#118）；自定义组件的删除按钮不再被导航栏挡住（#107）。
- 儿童推荐行改为请求儿童内容（#168）；音乐不再混入影视组件，单个媒体库失败也不影响已加载的内容（#170）。
- mpv 预加载的旧结果不会用到新一集，媒体信息显示真实队列状态（#177）。
- WebDAV 备份目录已存在但服务器拒绝创建时不再报失败（#135）。
- 飞牛空背景字段不再被当作已有背景图（#108）。
- 光盘流缓存按设备内存取 32–128 MiB。

## 升级

正式签名与包名延续既有版本，1.0.1 及以后的正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。

## 验证与已知限制

- 在合并后的候选代码上运行全部模块单元测试 3,274 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；TV lint 无错误。已核对包名、版本、ABI、正式签名、libdandansign 与包内无 AppSecret 明文。
- 杜比视界链路和 mpv 硬解在一加 PKT110 上验证过，P5、P8 使用合成样片。竖屏短剧、批量标记已看、追剧日历、字幕包选择等反馈修复只有单元测试，欢迎反馈。
- 夸克线路只用本地模拟服务器验证过，未使用真实夸克链接；emos 播放未在真实服务器上验证。
- 已知问题：mpv 播到结尾再往回拖后画面可能停住，暂停后再播放可恢复；刚切换内核且暂停时，媒体信息的编码和分辨率可能显示“未知”。
- #160 中“导入本地字幕不显示”未能复现，本版没有改动。
