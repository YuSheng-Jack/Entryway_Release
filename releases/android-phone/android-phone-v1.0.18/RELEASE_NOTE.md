# Entryway Android Phone 1.0.18

版本 1.0.18 · 构建号 78 · 正式 Release · Android 8.1+ · arm64-v8a

1.0.17 之后的功能版本：进度条拖动预览图、断网离线模式、自动选最快线路、卡顿诊断和意外中断续播，下载可以选版本，媒体库新增索引栏，移动云盘分享免登录播放，并汇总用户反馈 #243–#298 中手机端的问题。TV 独立发布 1.0.17；Entryway 永久免费。

## 新功能

**播放**
- 拖动进度条时显示预览图（Jellyfin trickplay、Emby / Plex 的 BIF 缩略图），进度条上标出片头和片尾。
- 卡顿诊断：播放卡住时，建议换一个码率更低的版本，或者先缓冲一会儿；不会转码。
- 意外中断续播：上次播放没正常停下（闪退、被系统杀掉）时，回到应用会提示停在哪里，可以接着看。
- 按剧学习跳过片头：手动跳过一次后，这部剧以后自动跳过，可以撤回；连续自动播放 3 集后，第 4 集前先问一句。
- ExoPlayer 播不了的视频类型会被记住，下次直接用 mpv；很长的多音轨 MP4 提前改用 mpv，避免内存不足闪退。
- 开播时说明这次沿用了哪些记住的选择（音轨、字幕等）。

**网络与服务器**
- 自动为当前网络选最快的服务器线路：冷启动、切换网络或离开 5 分钟后回来时重新测速，按网络分别记住；每台服务器可以在线路页单独关闭。
- 离线模式：断网或连不上服务器时，首页显示已下载的内容和本机的继续观看，并提供重试；离线时的播放进度在服务器恢复后补传。
- 打开详情页时先预热服务器连接，播放起得更快。

**下载**
- 可以选择下载哪个版本，默认选不超过 1080p 的最大版本；整季批量下载按同样规则为每一集选版本。
- 新增「优先下载」，把排队中的任务提到最前面。

**媒体库与详情页**
- 媒体库新增 A–Z、年份、评分索引栏；几千部的大库也能直接跳到任意字母（中文片名按拼音首字母）。
- 筛选条件显示实时数量；筛选结果为空时，给出「去掉某个条件 → 多少部」的放宽建议，点一下即可（Emby / Jellyfin）。
- 海报、背景图和剧照可以全屏查看，支持翻页和缩放。

**网盘与其他**
- 中国移动云盘分享链接不登录也能浏览和播放；修复 139 分享打不开（9530 功能参数值非法）。添加分享时不再要求移动云盘账号。
- AI 字幕新增「阿里云千问 Token Plan（个人版）」预设。
- 捐助名单新增 9 位，感谢支持。

## 修复与优化

- 投屏：转发时带上服务器的鉴权信息（飞牛令牌、Cookie 等），使用 Wi-Fi 地址而不是移动数据地址，支持 HLS；渲染器拒绝时用更简单的信息重试（#271）。
- mpv 下外挂字幕排在内嵌字幕前面，首选的内嵌字幕取不到时仍会选中外挂字幕（#253）。
- 精选合集卡片和详情页也会查找 CMS 影视源（#270）。
- UC网盘支持扫码登录（#276）。
- 新增「问题日志」：开始记录后复现问题，停止后生成脱敏的日志包，15 分钟后自动停止（#277）。
- 新增「继续观看点击」设置：直接播放（默认）或打开详情（#248）。
- 「重新登录」原地登录已保存的服务器，先用记住的密码静默重试，只在需要时询问密码，服务器不会变成新的一台（#289）。
- 搜索：服务器很多时不再卡住，最多同时查询 5 台，超时的服务器不再拖住整个页面（#295、#298）。
- 跨服务器资源默认按「详情页版本排序」选版本；大小或码率为 0 的版本按未知排序（#298）。
- 收藏、推荐、搜索和相似推荐里的横版封面不再被拉伸（#290）。
- 「发送到电视」带上服务器的备用线路和当前使用的线路（#292、#294）。
- IPTV、Navidrome、更新校验和日志脱敏的若干修复。

## 升级

正式签名和包名都与之前的版本相同，1.0.1 及以后的正式版可以直接覆盖升级。建议升级前先在「设置 › 备份与恢复」备份。
