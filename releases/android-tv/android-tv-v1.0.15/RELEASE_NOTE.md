# Entryway Android TV 1.0.15

版本 1.0.15 · 构建号 59 · 正式 Release · Android 6.0+ · arm64-v8a / armeabi-v7a

1.0.14 之后的功能版本：改善高码率播放和卡死恢复，首页提示新版本，详情页增加网站评分和获奖信息，并汇总用户反馈 #104–#173 中 TV 端的问题。手机独立发布 1.0.16；Entryway 永久免费。

## 新功能

- 首页服务器标签旁显示新版本提示，按一次上键可以选中并进入更新页。每天自动检查一次，检查失败不显示。
- 详情页简介下方显示 TMDB、IMDb、烂番茄、Letterboxd、Trakt、Metacritic 的评分，下方显示作品获得的知名奖项。评分需要在账号设置中用手机扫码填写自己的 MDBList API Key。
- 剧集卡片显示当前服务器可播的集数，支持标准 Emby 和 Jellyfin（#129）。
- 退出前询问确认，默认开启，可在设置中关闭（#165）。
- CMS 站点可以在添加表单、二维码页和配置中心填写 Cookie；落在夸克网盘的线路改用 16 连接分段读取。

## 修复

**播放**
- 超过 60 Mbps 的原始文件改用两条分段连接下载，ExoPlayer 和 mpv 都支持（#104、#159）。
- 播放 30 秒没有任何进度时自动刷新播放信息并恢复；暂停时继续缓冲（#156）。
- 播放时不再为面板磨砂效果复制视频帧，减少调出面板时的卡顿（#114、#124）。
- 天猫魔盒 M31H 这类全志芯片在 mpv 硬解 4K 时会出现绿色竖条，现在自动改用 ExoPlayer 并提示。原盘没有其他内核可用，仍走 mpv。
- emos 等服务器返回自有播放地址时按该地址播放（#161）。
- 没有文件选择器的盒子加载本地弹幕不再崩溃。

**页面与媒体库**
- 详情页加载失败不再停在骨架屏，改为显示原因和重试按钮。
- 终点站的“我的收藏”不再为空；类型筛选改为发送类型 ID，不再扫描整个媒体库。
- 飞牛主页和详情的背景图缺失时回退到海报（#108、#173）。
- 文件页默认显示视频和音频，FLAC 能看到了；已保存的筛选不变（#147、#148）。
- 海报和人物卡作为整体获得焦点，最后一行文字不再被裁切（#144）。
- 剧集列表不再只显示 50 集（#164）；音乐不再混入影视组件（#170）；儿童推荐行改为请求儿童内容（#168）。

**备份与诊断**
- 从 WebDAV 恢复后，返回键仍能关闭设置抽屉（#105）。
- WebDAV 备份目录已存在但服务器拒绝创建时不再报失败（#135）。
- 诊断导出失败时回退到剪贴板。

## 升级

正式签名与包名延续既有版本，1.0.1 及以后的正式版可直接覆盖升级。64 位系统安装 arm64-v8a 包，32 位系统安装 armeabi-v7a 包；应用内更新会自动选择。

## 验证与已知限制

- 在合并后的候选代码上运行全部模块单元测试 3,274 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；TV lint 无错误。已核对包名、版本、ABI、正式签名、libdandansign 与包内无 AppSecret 明文。
- 同代码测试包在天猫魔盒 M31H（Android 10）和当贝 DBBOX5C（Android 11）上验证了启动、首页、详情页、“我的收藏”、类型筛选和普通播放；正式包未在实机做全量验收。新版本提示要等下一个版本发布后才能在实机看到。
- 高码率双连接和卡死恢复只有单元与回环测试，未用真实超过 60 Mbps 的片源验证；夸克线路未使用真实链接，emos 未在真实服务器上验证。
- 已知问题：天猫魔盒 M31H 上 mpv 放 1080p H.264 可能卡顿，可改用 ExoPlayer；原盘 ISO 在部分电视上的问题（#184、#189）本版没有改动。
