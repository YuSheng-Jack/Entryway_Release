# Entryway Android TV 1.0.14

TV 独立正式版，构建号 **58**，Release + R8、正式发布证书签名，提供 arm64-v8a 与 armeabi-v7a 两个安装包。1.0.13 之后的反馈修复版本：播放中加载在线 / 本地字幕、推荐首页接入 MoviePilot 订阅、同地址多线路与缓冲预算修正、Jellyfin 官方片头片尾，汇总反馈 #112、#115、#117、#123、#127、#128、#133、#150–#153。手机版独立发布 1.0.15；Entryway 永久免费。

## 新功能

**字幕（#112）**
- 播放器字幕面板新增“在线搜索字幕”与“加载本地字幕”：在线搜索可用遥控器操作，来源包括服务器自带搜索及自己配置的 SubDL / OpenSubtitles / 射手凭据；本地字幕通过系统文件选择器导入 SRT / ASS / SSA / VTT / ZIP，回到播放器从原进度接着播。
- 压缩包字幕支持旧式 ZIP，中文文件名能正确读出；字幕下载跳转时不把服务器凭据带到其他网站。

**推荐首页**
- 推荐详情页可直接在 MoviePilot 订阅，季的选择按 TMDB 匹配结果；已入库的电影、已订阅的季不能重复订阅，入库查询失败时显示失败，不再说“没有”；TV 备份不含 MoviePilot 密码（#127）。
- 新增“热门国漫”“热门纪录片”“热门儿童片”片单（#133）。
- 推荐首页可进入各媒体库，“最近添加”可以打开；“我的”页统计在大字号下不被截断（#117）。
- 推荐详情页的演员可以点开（#128）。

## 修复与改进

- **同地址多条线路（#151）**：同一地址的“仅直连”与“走代理”线路互不串用；切换线路后 API、图片、Exo 与 mpv 视频流都随所选线路走，改线路、重新登录、重启后保持一致，正在播放的视频不会重新加载。
- **缓冲（#152）**：申请的缓冲按设备安全预算截断，设置 › 网络与缓存 › 播放缓冲显示 Exo 与 mpv 的实际预算。
- **Jellyfin 片头片尾（#153）**：读取服务器识别的全部片段类型，片尾不超出片长；按返回键关掉跳过按钮后自动跳过照常生效；手动设置的片头片尾优先。
- 媒体库网格改排序后首页对应行跟着变；新增“播放时钟常驻”（#150）。
- 剧集库“最近添加”中有新集的剧排到前面（#115）。
- Android 7 以下的盒子能恢复手机导出的加密备份（#123）。
- 字体调大时播放器按钮行可滚动，剧集上的“信息”按钮能选中。
- 媒体信息里的杜比视界 Profile 名称按真实编号显示（原先 P5、P8 会显示成别的编号）。
- 实机测试中发现并修复：Exo 播放启动即崩溃、带线路的服务器播放时“获取播放信息失败”（服务器响应 5–6 秒即超时）、在线搜索字幕用遥控器无法离开关键词输入框。

## 安装

已安装 TV 1.0.1 及以后的正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。64 位系统选择 arm64-v8a，32 位系统选择 armeabi-v7a。1.0.13 起应用内更新由双云下载服务提供。

## 验证与已知限制

- 在合并后的 main 上运行全部模块单元测试 2,876 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；`:tv-app:lintDebug` 无错误。
- 已核对包名、版本、ABI、正式签名、弹弹Play native signer，包内无 AppSecret 明文。
- 实机验证（天猫魔盒 M31H，Android 10，armeabi-v7a，同代码调试包）：手机加密备份恢复、Exo 播放、67 Mbps 4K HDR10 片源 Exo 缓冲预算约 8 秒且无 “less than 500ms” 告警、缓冲预算摘要、剧集按钮行、在线字幕遥控操作、推荐首页新片单、推荐详情演员页。
- 以下未在实机验证：#151 代理线路（需代理环境）、#153（需 Jellyfin 10.10+）、#127 MoviePilot 订阅、#123（需 Android 7 以下设备）、#150、#115、#117、本地字幕导入与 mpv 缓冲；欢迎反馈。
- mpv 的网络吞吐（#152）本版未改动，只做观察。
