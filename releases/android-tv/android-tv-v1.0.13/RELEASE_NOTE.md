# Entryway Android TV 1.0.13

TV 独立正式版，构建号 **57**，Release + R8、正式发布证书签名，提供 arm64-v8a 与 armeabi-v7a 两个安装包。1.0.12 之后的功能版本：推荐首页改版为独立“服务器”、无需 TMDB 密钥、详情可直接播放，搜索提速，按设备能力选择流畅的版本，并汇总反馈 #81、#100–#103。手机版独立发布 1.0.14；Entryway 永久免费。

## 新功能

**推荐首页**
- 推荐首页像一台独立的服务器：与服务器首页相同的左侧导航栏，左上角胶囊显示“推荐首页”。页面为大幅剧照配艺术字标题、年份、类型与简介，下方是分类标签（更新推荐、猜你喜欢、热门电影……电视剧榜单，电影 / 电视筛选可选类型）和竖版海报；右上角“自定义首页”可编辑分类。
- 无需 TMDB 密钥：推荐内容默认来自豆瓣；填写自己的 TMDB 密钥后，豆瓣失败或过慢时自动改用 TMDB，未填写时页面会提示。
- 推荐影片的详情页与服务器详情页一致，信息优先取自 TMDB：自动检索全部服务器，按“多版本时优先”在 3 秒内选出主服务器，可直接播放，版本、字幕、音轨都能选，剧集显示季与分集；“服务器资源”标出当前服并列出其他服务器的版本。
- 推荐影片的详情、服务器资源与剧集分集每天自动缓存，详情约 1 秒打开；不在推荐里的影片在下次刷新时清除，新加入的自动补上。
- 海报与剧照改用高分辨率图片。

**播放**
- 多个版本未指定时，优先选本机能流畅播放的版本：避开没有杜比视界硬件时的 Profile 5、超出解码能力的规格以及低端机上的 4K 60 帧；手动与记住的选择不受影响。
- 持续掉帧时，卡顿提示会到其他服务器寻找更容易播放的版本，提供“切换版本”，从当前进度接着播。
- 播放器顶栏在片名下显示正在播放的服务器（#100）。

**搜索、媒体库与配置**
- 搜索提速：各服务器的片名列表保存在本机，启动后在后台准备好，进入搜索即可搜索；过期的列表在后台更新，较大的媒体库分页并行读取。
- 媒体库按片名、上映日期或评分排序时，右侧有索引栏可按字母、年份或分数跳转；按住方向键显示“第 N 部 / 共 M 部”。
- “从手机导入”与“用手机配置”合并为一个入口，配置页可直接上传备份文件；尚未添加服务器时也能在添加服务器页用手机配置。
- 跨版本恢复手机备份与“发送到电视”：逐项导入，未能导入的项目单独列出。
- 检查更新与下载安装包改用自有双云下载服务（杭州为主、上海备用、GitHub 兜底），按系统 ABI 选择 64 位或 32 位安装包，支持断点续传与 SHA-256、签名校验。
- Trakt 同步更准确：超过 5 分钟才补发的“看完”按原始观看时间写入历史；30 分钟内未发出的“开始播放”不再补发；重试时先查历史，已写入就不再重复。

## 性能

- 杜比视界 Profile 5 在弱 GPU 上自动改用预先计算的色彩映射：天猫魔盒每帧处理从 25–50 毫秒降到 11–14 毫秒，4K 60 帧不再被限制在约 25 帧。

## 修复

- 退出跨服版本切换后回到原来的服务器与页面，播放记录记在对应服务器上（#102）。
- 播放器自动切换内核时在屏幕上说明原因，并记录每次自动切换（#103）。
- 媒体库、搜索、人物、影视库网格统一使用首页海报卡片，下方显示“年份 · ★评分”（#101）。
- 首页侧栏循环移动：在“设置”上按上键到“服务器”，在最后一项按下键回到顶部（#81）。
- 低端机不支持的“ASS 特效字幕”会提示不支持，不再看似开启却无效。
- 字体调大时，搜索页的“片名 / 演员”切换不再被切掉一截，键盘最后一行数字也不再超出屏幕（键按剩余高度缩放，正常字号下不变）。

## 安装

已安装 TV 1.0.1 及以后的正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。64 位系统选择 arm64-v8a，32 位系统选择 armeabi-v7a。1.0.12 及更早版本仍通过原有渠道发现本次更新；升级到 1.0.13 后，之后的更新改由双云下载服务提供。

## 验证与已知限制

- 在合并后的 main 上运行全部模块单元测试 2,648 项：0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；`:tv-app:lintDebug` 无错误。已核对包名、版本、ABI、正式签名（v1 + v2）、弹弹Play native signer，包内无 AppSecret 明文。
- 正式包实机验证：arm64-v8a 在 MediaTek 投影仪（Android 11，1080p，较大字号）上由 1.0.12 正式版覆盖升级，数据保留，首页、续播与搜索正常；armeabi-v7a 在天猫魔盒 M31H（Android 10，32 位）上验证推荐首页、推荐详情（缓存的服务器资源、直接播放、返回详情）与搜索。
- 没有 TMDB 密钥时推荐内容与详情来自豆瓣；豆瓣对单个公网地址的访问有频率限制，配置 TMDB 密钥后后台预缓存不再调用豆瓣影片页。
