# Entryway Android TV 1.0.16

版本 1.0.16 · 构建号 60 · 正式 Release · Android 6.0+ · arm64-v8a / armeabi-v7a

1.0.15 之后的功能版本：新增紧凑播放控件、HDR 转 SDR、mpv 次字幕，资源里可以直接播放网盘分享链接，新增 AList / OpenList 和 UC网盘，并汇总用户反馈 #183–#239 中 TV 端的问题。手机独立发布 1.0.17；Entryway 永久免费。

## 新功能

**播放**
- 紧凑播放控件：在「设置 › 播放行为 › 播放器界面」选择「紧凑」（新）或「经典」（原样保留）。紧凑模式有更薄的顶栏、带拖动预览图的进度条（Emby BIF / Jellyfin trickplay）、状态行和「更多」面板；快捷栏的按钮可以自选并调整顺序（#201）。
- 「设置 › 播放 › HDR 转 SDR」：给显示不了 HDR 的电视用。开启后，HDR / HLG / 杜比视界片源由 mpv 转成 SDR 输出；正在用 ExoPlayer 时，会提示后自动切到 mpv（#188）。
- mpv 下字幕面板新增「次字幕」页，内嵌和外挂的文字字幕都可以选，切换下一个视频时自动关闭（#210）。
- 「设置 › 播放」新增「高码率多连接取流」开关。

**服务器与首页**
- 在「切换服务器」里按 OK，会弹出「使用此服务器 / 备用线路 / 编辑线路」；正在使用且只有一条线路的服务器，按 OK 直接回到首页（#232）。
- 在首页长按服务器胶囊，直接打开当前服务器的线路列表（#233）。
- 编辑分类新增「移到最前」「移到最后」（#238）。

**网盘与资源**
- 新增网盘分享链接（夸克、115、天翼云）、AList / OpenList、UC网盘，各自有独立的编辑页，可以扫码用手机填写；UC网盘粘贴 Cookie 登录。登录失效的卡片显示「需要重新登录」，可以原地重新登录；AList 存储可以全盘搜索，`/dav` 存储可以改用 API 连接；在分享的选项里可以设置是否同意临时转存。
- TVBox：多仓可以选择具体配置，导入时显示跳过报告，可选用 hosts / DoH 和广告过滤，支持 T4 站点和 T4 字幕；点播分类上方的「筛选」行可以用遥控器操作。

**其他**
- 网站评分的扫码表单可以填写豆瓣 Cookie；MDBList Key 和豆瓣 Cookie 填其中一个就能显示评分行（#193）。
- TMDB 列表行改用无文字海报（#198）。
- 兼容没有系统文件选择器的盒子：本地字幕、本地弹幕、备份恢复、账本恢复和壁纸，都可以通过 ES 等文件管理器选文件（用 ES 时请选「文件方式」）。备份导出到 `Download/Entryway`，并且一定加密（#202、#208）。

## 优化

- 播放器里「下一集」排在「上一集」前面，并默认获得焦点（#229）。
- 常驻时钟和网速文字去掉黑色底块，改为文字阴影（#231）。
- 顶部大标题统一使用剧名艺术字：继续观看里的单集显示所属剧集的标志图，没有才显示文字（#239）。
- mpv 取流的并发按内存调整，内存不足 192 MiB 的盒子不开多连接（#187、#204、#211）。
- 「Exo 音频解码」设置真正生效：选「优先软解」时，FFmpeg 音频解码排在前面（#207）。
- 在线字幕搜索结果每条单独一行，显示语言、格式、来源、下载数和评分（#215）。
- 文件列表统一自然排序（#191）；豆瓣近期片单（#198）；追剧日历返回整天全部集数（#195）；备份包含脚本组件和精选合集（#208）。
- 弹幕面板用你的语言说明失败原因。

## 修复

- ExoPlayer 加载外挂字幕时崩溃；字幕显示「已加载」但不出字；播完最后一句后反复重播最后一句（#202）。
- 小米等电视上，退出对话框的按钮拿不到焦点（#189、#237）。
- 部分启动器（尤其 Android 6）按 Home 后再点图标，看起来像打开了第二个 Entryway（#224）。
- 从顶部服务器胶囊打开「切换服务器」时，焦点被首页抢走。
- 光盘 ISO 在限制连接数的服务器上频繁缓冲（#184、#189、#203）。
- 部分 SMB 服务器列不出共享（#200）；飞牛 fnOS 的海报和背景图缺失（#205、#209）。

## 升级

正式签名和包名都与之前的版本相同，1.0.1 及以后的正式版可以直接覆盖升级。64 位系统装 arm64-v8a 包，32 位系统装 armeabi-v7a 包；应用内更新会自动选择合适的包。

## 验证与已知限制

- 在合并后的候选代码上，全部模块单元测试 3,601 项，0 失败。已核对包名、版本、ABI、正式签名、libdandansign，并确认包内没有 AppSecret 明文。
- 紧凑播放控件的设备测试在当贝和天猫魔盒上 10/10 通过；与经典界面相比，天猫魔盒上的慢帧减少一半，但打开 / 收起的瞬间仍偶有超过 32 ms 的帧。拖动预览图只用本地测试服务器验证过。
- #229、#231、#232、#233、#238 已在当贝和天猫魔盒上验证；#202 外挂字幕和文件选择器已在 M31H 上验证。HDR 转 SDR、网盘分享、AList、UC网盘和 TVBox 新功能目前只有单元测试或模拟服务器验证，欢迎反馈。
