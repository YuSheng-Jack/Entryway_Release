# Entryway Android TV 1.0.12

TV 独立正式版，构建号 **56**，Release + R8、正式发布证书签名，提供 arm64-v8a 与 armeabi-v7a 两个安装包。手机版独立发布 1.0.13；Entryway 永久免费。

## 更新

- **设备三档（高/中/低）与资源预算**：启动时按内存、CPU 与硬件解码能力分档，缓冲、预热、图片缓存、并发连接、毛玻璃/动效与弹幕绘制随档位调整；内存吃紧时自动降档并在恢复后回升。设置里可手动指定档位，并可本机查看、复制诊断（不含服务器、账号、片名和链接，不自动上传）。
- 按实测解码能力协商直放与转码：保守软解、STRM 直放不受转码码率限制、需要转码时按档位限制输出码率；首帧前的解码失败会记录并在切换媒体时重置，Exo 未选中轨道时恢复画面，检测卡帧并限制 mpv 软解负载。
- mpv 播放 Dolby Vision Profile 5/8 时交给系统解码器（受信平台，荣耀/华为屏和 HDR10 设置不进入），失败或超时自动回到常规路径。
- 修复飞牛把普通视频报为 `dv_profile=0` 时被当成杜比视界、只有声音没有画面的问题（#50）。
- SMB 播放提速：SMB 3.1.1 协商、空闲会话过期重建、1 MiB 预读，慢服务器不再拖住其他存储（#59）。
- 人物页显示年龄与去世日期，遥控器可滚动简介（#40）；“我的媒体库”排序增加首映日期（#49）。
- 上一集/下一集在当前服务器上跳过同一集的其他版本（#47）；操作按钮与播放器控件随全局字号缩放（#51）。
- 兼容性：改进 Android 6 设备上的若干问题。

## 已知限制与反馈重点

- **设备三档尚无有效真机灰度报告**，目前的验证来自单元测试、lint、模拟器回归与正式配置构建；分档阈值、首页流畅度、内存占用和长时间播放稳定性仍需真机数据。若出现卡顿或误降档，请在设置里手动选择档位，并附诊断反馈。
- mpv 原生 4K HEVC 欠载及冷续播崩溃仍未完成根因修复与真机闭环；已知 DBBOX5C / rk30board / Android 11 保留 ExoPlayer 保护。
- Dolby Vision 系统解码路径在更多电视/盒子上的兼容性待验证。
- 本次正式包未安装到实机验收。本轮在合并后的 main 上运行全部模块单元测试 2,290 项：2,287 通过、0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过；已核对包名、版本、ABI、正式签名、非调试属性与弹弹Play native signer，包内无 AppSecret 明文。

反馈请附设备型号、系统版本、服务器类型、所用引擎、影片编码/分辨率、诊断信息与复现步骤；请勿公开账号密码或带令牌的播放链接。

## 安装

已安装 TV 1.0.1 及以后正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。64 位系统选择 arm64-v8a，32 位系统选择 armeabi-v7a。灰度包（`com.entryway.tv.tierpreview`，“Entryway TV 灰度”）与正式版包名不同，可并存，不会自动迁移数据。更早的不同签名版本需先备份，再卸载旧版、安装并恢复。
