# Entryway Android TV 1.0.12

TV 独立正式版，构建号 **56**，Release + R8、正式发布证书签名，提供 arm64-v8a 与 armeabi-v7a 两个安装包。这是 1.0.11 之后的完整功能版本：新增设备三档与资源预算、杜比视界新播放路径、TMDB 聚合推荐首页，并汇总飞牛、SMB、IPTV/TVBox 与多条用户反馈修复。手机版独立发布 1.0.13；Entryway 永久免费。

## 新功能

**设备三档与资源预算**
- 启动时按内存、CPU 与硬件解码能力分为高/中/低三档；缓冲、预热、图片缓存、并发连接、毛玻璃/动效与弹幕绘制随档位调整，内存吃紧时自动降档、恢复后回升。
- 按实测解码能力协商直放与转码：保守软解，STRM 直放不受转码码率限制，需要转码时按档位限制输出码率；检测卡帧、限制 mpv 软解负载，Exo 未选中轨道时自动恢复画面。
- 设置中可手动指定档位，并可在本机查看、复制诊断信息（不含服务器、账号、片名和链接，不自动上传）。

**杜比视界**
- 杜比视界硬件修正路径：mpv 支持 mediacodec-copy 硬解修正（着色器缓存、首帧后校验），改善不支持 HDR 的电视播放 DV 片源被迫软解、卡顿的问题（#57）。播放信息新增视频解码器与杜比视界行。
- mpv 播放 Dolby Vision Profile 5/8 时可交给系统解码器（受信平台，荣耀/华为屏与 HDR10 设置不进入），失败或超时自动回到常规路径。

**首页与浏览**
- TMDB 聚合推荐首页：可新建、编辑多个推荐页，详情页聚合多服务器资源，并可在侧边栏切换（#10）。
- 人物页显示年龄与去世日期，遥控器可滚动简介（#40）；“我的媒体库”排序增加首映日期（#49）。
- 操作按钮与播放器控件随全局字号缩放（#51）。

**飞牛、线路与网络**
- 多线路自动故障切换：线路不可用时自动换到其他可用线路（#15、#26）。
- 飞牛：完整媒体库分页（大库、多库不再截断）、IPTV 频道、外挂字幕下载；每路播放独立会话，先关闭旧转码；FN Connect 访问码与网关 Cookie（#35）；FN Connect 中转不再收到登录页，FN ID / FN Connect 下的 ISO 给出明确提示。
- SMB 播放提速：SMB 3.1.1 协商、空闲会话过期重建、1 MiB 预读，慢服务器不再拖住其他存储（#59）。
- IPTV 播放列表上下文解析更稳健，TVBox 配置子集解码改进。

**其他**
- 用户群迁移到 Telegram（Entryway Buddys），关于页二维码随之更新；致谢名单新增三位支持者。

## 修复

- 修复飞牛把普通视频报为 `dv_profile=0` 时被当成杜比视界、只有声音没有画面（#50）。
- 上一集/下一集在当前服务器上跳过同一集的其他版本（#47）。
- 人物详情页无法打开等问题修正（#46），以及 Android 6 设备上的若干兼容性问题。
- 关闭开屏致谢后，恢复界面时不再重新出现致谢层（#25）。

## 已知限制与反馈重点

- **设备三档尚无有效真机灰度报告**：目前的验证来自单元测试、lint、模拟器回归与正式配置构建；分档阈值、首页流畅度、内存占用和长时间播放稳定性仍需真机数据。出现卡顿或误降档时可在设置中手动选择档位，并附诊断反馈。
- 杜比视界两条新路径在更多电视/盒子上的兼容性待验证。
- mpv 原生 4K HEVC 欠载及冷续播崩溃仍未完成根因修复与真机闭环；已知 DBBOX5C / rk30board / Android 11 保留 ExoPlayer 保护。
- 本轮在合并后的 main 上运行全部模块单元测试 2,468 项：2,465 通过、0 失败，3 项因缺少 DVD/Blu-ray 宿主夹具跳过。已核对包名、版本、ABI、正式签名（v1 + v2）、非调试属性与弹弹Play native signer，包内无 AppSecret 明文；本次正式包未安装到实机验收。

反馈请附设备型号、系统版本、服务器类型、所用引擎、影片编码/分辨率、诊断信息与复现步骤；请勿公开账号密码或带令牌的播放链接。

## 安装

已安装 TV 1.0.1 及以后正式版可直接覆盖升级，建议先在「设置 › 备份与恢复」备份。64 位系统选择 arm64-v8a，32 位系统选择 armeabi-v7a。灰度包（`com.entryway.tv.tierpreview`，“Entryway TV 灰度”）与正式版包名不同，可并存，不会自动迁移数据。更早的不同签名版本需先备份，再卸载旧版、安装并恢复。
