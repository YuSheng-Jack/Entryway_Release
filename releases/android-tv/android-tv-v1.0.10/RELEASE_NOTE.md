# Entryway Android TV 1.0.10

版本 1.0.10 · 构建号 54 · Release · Android 6.0+ · arm64-v8a / armeabi-v7a

## 主要更新

- “我的”接入本地可信观看账本、年度统计与票根；新增音乐账本、专辑封面和黑胶票根，音乐计时接入现有 Exo 播放服务。
- 内容字号支持 100%–300%，导航与弹窗保留基准字号；放大首页 Hero，媒体库网格按宽度显示 8–12 列。
- 集中管理媒体库显隐和排序，导航与服务器首页分别保存；媒体库壁纸可选当日 Hero、上传图片或指定影片，并调节模糊与可见度。
- TV 配置中心支持媒体服务器与弹幕接口管理，手机导入失败时返回具体原因；扫码录入、编辑与备份完整传递 FN Connect 模式。
- 关于页加入片尾式致谢，开屏加入动态 Logo、烟花与随机致谢名单。
- 接入共享 AI 字幕翻译/识别会话，改善图片响应头兼容与屏保计时。

## 兼容与修复

- FN Connect 保留原 FN ID 入口，动态发现地址并校验 NAS 身份；失效地址重新解析，只读请求最多重试一次，影视/音乐请求与播放授权使用一致的运行时地址。
- 服务器录入与编辑更紧凑，补齐 FN 模式的编辑、扫码与备份传递，留空密码可保留已有授权。
- 账本升级支持 V1→V2 迁移与 schema 1/2/3 备份兼容，保留音乐元数据和删除标记，重复导入按幂等规则合并。
- 改善飞牛 HEVC、HDR / Dolby Vision Profile 元数据，以及下载重试、文件完整性检查、WebDAV 流式解析与大型 IPTV 列表处理。
- 保留 1.0.9 的 HLS 分片预取、媒体服务器发送到电视和 IPTV 死链抽样拒绝；完善 HLS 缓存/取消隔离、Android 6 FutureTask 兼容与导入失败提示。

## 安装与已知限制

- 本次为正式密钥签名、R8 优化的 Release 构建。1.0.1 及之后正式版可覆盖升级；更早的不同签名版本请先备份，再卸载、安装与恢复。
- FN Connect 的可用路径取决于 NAS 与网络条件；真实外网、relay 和网络切换尚未完成完整验证。
- 完整音乐计时、票根与界面场景矩阵尚未全部完成；已执行的 Preview 局部真机检查不能等同于本次正式包的完整真机验收。
- 其他平台保持其独立当前版本。
