# Entryway Android TV 1.0.18

版本 1.0.18 · 构建号 62 · 正式 Release · Android 6.0+ · arm64-v8a / armeabi-v7a

1.0.17 之后的功能版本：新增 SDR 转 HDR 和 HDR 转杜比视界，杜比视界处理全面增强；IPTV 回放可以直接打开节目单、回到直播，播放器新增截图和弹幕速度调节，较旧的 Android TV 也支持「继续观看」频道；详情页、媒体库和搜索更快更稳，并汇总用户反馈 #301–#342 中 TV 端的问题。手机独立发布 1.0.19；Entryway 永久免费。

## 新功能

**杜比视界与 HDR**
- SDR 转 HDR：普通 SDR 视频实时转成 HDR 显示，播放器面板里可以用遥控器开关、调参数，并显示当前是否已在输出 HDR；全局设置对 DLNA 投屏播放同样生效，出问题时自动回到直接输出。
- HDR 转杜比视界：在支持杜比视界的电视上，HDR10+ / HDR10 / HLG 视频可以转成杜比视界 Profile 8.1 / 8.4 播放，可选自动（默认）、关闭、仅 HDR10+、全部 HDR。
- 杜比视界增强：可以设置 SDR 目标亮度、L5 黑边和 CMv4.0；播放中用遥控器快速切换杜比视界处理方式，并查看信号链信息；mpv 支持 Profile 7 转 8.1；PGS 字幕在 BT.2020 画面下颜色正确。

**播放**
- IPTV 回放时也能打开节目单和「回到直播」，日期改为横向标签，回放进度和直播互不影响（#310、#311、#318）。
- 经典播放控制栏新增截图（#339）。
- 播放器里可以调弹幕速度并实时预览（#304）。
- 识别蓝光 M2TS 文件；mpv 续播时预先缓冲，起播更稳。

**系统**
- 较旧的 Android TV（Android 8–11）也能在系统首页显示「继续观看」频道；较新的 Google TV 不再出现重复的两行（#319）。
- 长按确认键改为按住即弹出操作，松开不会误触点击（#303）。
- 新增线路的「仅直连」设置会被记住，返回后再进入不再变回关闭（#340）。

## 修复与优化

- 搜索：大幅降低片名索引占用的内存，修复搜索时卡在「正在读取片名」后闪退（#301）；首字母和中英混合拼音可以搜到 CMS 片源（#312、#313）。
- 详情页：季、集和续播位置并行加载，打开更快（#321）；光标移到其他集时显示这一集的版本和音轨信息（#316）；遥控器向下键不再跳过季这一行（#342）。
- 媒体库：文件夹保留所选排序（#320）；修复每个文件夹只显示前 35 部、要等很久才加载剩余内容（#341）。
- ISO：先检查文件内容，名字是 .iso 但其实是普通视频的（例如移动云盘洗码的假 ISO）继续用 ExoPlayer 播放（#328）；Emby 云盘服中 strm 指向的 ISO 在没有跳转地址或不支持分段读取时自动改用直接地址，远程 ISO 打开和拖动更快（#302、#335）。
- 网盘直链过期或被限速时自动刷新地址，遇到 429 / 5xx 和不完整的数据会重试；高码率直链不再写入闪存缓存；各档设备优先使用 Surface 硬解（#330、#331、#332）。
- 继续观看：某台服务器刷新失败时，保留其他服务器和之前缓存的记录（#338）。
- IPTV 的 EPG 下载或解析失败后会重试，不再等一小时（#317）；分类标错的 CMS 片源不再被过滤掉（#326）。
- 全志盒子（如 M31H）偶发 HDR 起播时解码器失败、画面卡死并无响应，现在会自动恢复并重试。
- 修复 mpv 音频直通失败回退时可能卡死。
- 弹幕绘制更省，盒子上的帧耗时明显降低。

## 升级

正式签名和包名都与之前的版本相同，1.0.1 及以后的正式版可以直接覆盖升级。64 位系统安装 arm64-v8a 包，32 位系统安装 armeabi-v7a 包，应用内更新会自动选择。建议升级前先在「设置 › 备份与恢复」备份。
